# 🏬 Qreta • Instant Digital Storefront

[demo](https://qreta.com) — [github](https://github.com/your-username/qreta) — [docs](https://docs.qreta.com) — [discord](https://discord.gg/your-invite-link)

> **Qreta** is a modern business platform that transforms physical spaces into digital storefronts. With a simple QR code scan, customers instantly access your entire product catalog, services, and business information—bridging the gap between physical presence and digital commerce.

## 🚀 Features

- **Instant Digital Storefront**: One QR code connects customers to your entire business
- **Multi-Business Management**: Manage multiple businesses from a single dashboard
- **Real-time Analytics**: Track orders, customers, and sales performance
- **Subscription Management**: Flexible plans with seamless payment integration
- **Mobile-First Design**: Optimized for customer mobile experiences
- **White-label Ready**: Custom branding options for agencies and resellers

## 🛠️ Stack

1. **Frontend**: [Next.js 15](https://nextjs.org) + [React 19](https://react.dev) + [TypeScript](https://typescriptlang.org)
2. **Styling**: [Tailwind CSS](https://tailwindcss.com) + [shadcn/ui](https://ui.shadcn.com)
3. **Database**: [MySQL/MariaDB](https://mysql.com) with [Prisma ORM](https://prisma.io)
4. **Authentication**: Custom auth system with secure session management
5. **Payments**: Integrated subscription billing system
6. **QR Generation**: Dynamic QR code generation with custom branding
7. **Deployment**: Optimized for [Vercel](https://vercel.com) deployment
8. **Real-time Updates**: WebSocket integration for live order tracking
